# Blog Platform with Comments

A full-stack blogging platform built as part of the Web Development assignment. This project allows users to register, create and manage blog posts, and interact through a comment system.

## Key Features
- **User Authentication:** User registration and login system.
- **Blog Management (CRUD):** Create, view, edit, and delete blog posts.
- **Interactive Comments:** Comment section under posts for user interaction.
- **RESTful API Backend:** Built with server and database integration for persistent data storage.
- **Responsive Interface:** Designed to work across web and mobile screens.

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js / Express.js
- **Database:** MongoDB / PostgreSQL
